# Чеклист перед merge

Использовать перед нажатием **Merge** (или перед пушем в `main`, если без PR).

## Проверки

- [ ] `bash flow_review.sh` прошёл локально (или как минимум `bash review.sh`).
- [ ] На GitHub **Actions** зелёные прогоны для этой ветки / PR.
- [ ] В diff **нет** `.env`, ключей, PEM, токенов, URL с вшитыми секретами.
- [ ] Не коммитились `.venv`, артефакты `tooling/logs/`, личные креды.

## LLM

- [ ] Если гоняли `diff_review` / облако: в промпт ушёл только текст после **guard** (`safe_snippet`), без прод-секретов.

## Смысл изменений

- [ ] Кратко понятно ревьюеру: **зачем** изменение и **как проверить** вручную.

После merge — при необходимости см. [[deployer-checklist]].
