# Deployer — ручной чеклист

Роль **Deployer** в этом репозитории **только документируется**: из кода и CI **нет** доступа к продакшену, нет вызовов API прод, нет хранения прод-секретов в git.

Исполняет человек с отдельными учётными данными и доступом к целевой среде.

## Перед выкладкой

- [ ] Merge в целевую ветку уже сделан; CI на ней зелёный.
- [ ] Принят **rollback-план** (как откатить релиз / конфиг).
- [ ] Секреты для прода взяты **не из репозитория** (секрет-менеджер, переменные CI платформы, `.secrets/` только локально и никогда в промпт).

## Во время

- [ ] Версия / артефакт однозначно идентифицированы (tag, билд-ID).
- [ ] Миграции БД и флаги включения учтены по порядку.
- [ ] После деплоя — смоук-тест минимально критичного сценария.

## После

- [ ] Зафиксированы время, версия и ответственный (ticket / заметка / runbook).
