# Личное (`personal/`)

Сюда кладём **несекьюрити** черновики, заметки, примеры для локальных скриптов — то, что не относится к `commercial/` и не является чужим кодом в `external/`.

## Связь с `coder_smoke.py`

Скрипт `tooling/coder_smoke.py` по умолчанию читает **`personal/readme.txt`** (если файл есть) и отправляет текст в локальную модель **после** `guard`. Не помещайте туда ключи и пароли.

## Git

При необходимости целиком добавьте `personal/` в `.git/info/exclude` или используйте отдельный приватный репозиторий — здесь файл `readme.txt` может быть уже в вашем дереве осознанно.
